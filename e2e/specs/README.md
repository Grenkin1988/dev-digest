# e2e — specs

The executable flows are `NN-name.flow.json` files in this folder (run by `../run.ts`;
`.md` files are ignored). Keep one row per flow, and add a row for each new one.

| Flow | Covers |
|------|--------|
| `01-app-boot.flow.json` | App boots and lands on the seeded repo's PR list |
| `02-repo-pulls-detail.flow.json` | Repo PR list and detail |
| `03-agents.flow.json` | Agents screen |
| `04-pr-findings.flow.json` | PR findings |
| `05-pr-diff.flow.json` | PR diff view |
| `06-onboarding.flow.json` | Onboarding |
| `07-settings.flow.json` | Settings |
